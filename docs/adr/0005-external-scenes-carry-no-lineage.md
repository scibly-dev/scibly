# External scenes carry no lineage

The external MCP surface exposes course authoring without notebooks: no
sources, no lineage, no image generation. Scenes written by an external agent
therefore cite nothing, and the freshness machinery (stale source → outdated
scene) never watches them — deliberately, not as an oversight. External agents
bring their own material, and grounding lives with whoever holds the material;
pulling notebooks into the MCP surface would have meant binding sessions to a
notebook and reworking every tool contract for a v1 nobody had asked to
ground. Revisit if external agents need to author from documents uploaded to
Scibly — that reopens notebook binding, not just a tool flag.
