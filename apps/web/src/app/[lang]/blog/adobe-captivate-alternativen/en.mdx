Adobe Captivate isn't being discontinued entirely, but the current desktop version "Captivate Classic" is being phased out: regular support ends August 23, 2026, extended support August 23, 2027. If you're still working with old .cptx projects, now is the time to plan, not once support actually ends. Adobe itself offers a new, subscription-based version, but many teams are using this moment to switch tools entirely.

## What's changing with Adobe Captivate

Three things matter for users:

| Change                                   | What it means                                                              |
| ---------------------------------------- | -------------------------------------------------------------------------- |
| Perpetual licenses discontinued          | New customers can only buy subscription licenses, no more one-time payment |
| Captivate Classic support ends 8/23/2026 | No more updates or bug fixes for the current desktop version after that    |
| Extended support until 8/23/2027         | Last window for critical security updates, then fully unsupported          |

Existing .cptx project files will mostly keep working technically after support ends, but without vendor support for problems, and without compatibility updates for new operating systems or browsers.

## What matters when switching

Before picking a new tool, it's worth doing a quick inventory:

- **How many existing courses need to be migrated?** A 1:1 migration of Captivate projects into another tool is rarely possible automatically; most of the time at least partial rebuilding is required.
- **Do you actually need Captivate's depth of interactivity?** Captivate was strong at software simulations and variable-based interactions. Many standard courses don't need that depth at all.
- **How often will new courses be created going forward?** If course creation is infrequent, a lighter, faster-to-learn tool is often worth more than another complex authoring tool.

## Alternatives at a glance

| Alternative                           | Strength                                                                           | Best for                                                                        |
| ------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Articulate 360 (Storyline/Rise)       | Established standard, large community, similar depth of interactivity to Captivate | Teams with a dedicated authoring team who build courses regularly               |
| iSpring Suite                         | PowerPoint integration, shallower learning curve                                   | Teams that already work heavily in PowerPoint                                   |
| H5P                                   | Free, open source, browser-based                                                   | Small budgets, technically capable teams                                        |
| New Adobe Captivate (subscription)    | Direct switch without changing tools                                               | Teams that want to stay within the Adobe ecosystem                              |
| Document-based AI tools (e.g. Scibly) | Course is generated from an existing document, no authoring-tool training needed   | Teams without a dedicated ID team who want to go from content to course quickly |

That last point is the real difference from a plain tool swap: if you have to migrate anyway, you can use the occasion to switch from "learn to operate an authoring tool" to "upload the document you already have," instead of just trading one authoring tool's name for another.

## Frequently asked questions

### Do I need to migrate my Captivate courses immediately?

Not immediately, but you should start planning now. Regular support continues until 8/23/2026, and extended support for critical fixes until 8/23/2027. After that, there's no more vendor support for Captivate Classic.

### Will old Captivate courses still work after support ends?

Already-published courses mostly keep running technically, but without any guarantee of compatibility with future browser or operating system updates, and without the ability to get bugs fixed by the vendor.

### Is the new Adobe Captivate the same as Captivate Classic?

No, it's a new, cloud/subscription-based version with a partly different feature set. A direct switch within Adobe is possible, but there's no automatic 1:1 migration of existing projects.

### Which alternative requires the least onboarding time?

Document-based AI tools and PowerPoint-adjacent tools like iSpring have the shallowest learning curve, because they build on workflows people already know. Classic authoring tools like Storyline or the new Captivate offer more design depth, but also require more ramp-up time.
