# `ee/`

Enterprise/commercial-only code: the Stripe billing integration
([billing](billing)) and the organization billing screen it powers
([organizations-billing](organizations-billing)). This is the part of the
product a self-hoster doesn't need — running your own instance has no reason
to talk to Stripe.

repository — see [LICENSE](LICENSE). It's source-available: you can read,
modify, and evaluate it, but production use requires a license from Scibly.
