# Entitlement

What an organization's subscription lets it do, and what it still owes when it
can't. Every refusal an organization sees — a 402, a locked control, a disabled
button — is decided here.

## Language

### What a plan sells

**Plan**:
What a subscription tier includes: seats, sources per notebook, BYOAI, anonymous
sessions, ad-free public courses, and a generation allowance.
_Avoid_: tier (the notebook context uses _tier_ for something unrelated), package

**Ad-free public courses**:
The paid-plan feature of public courses carrying no pitch scene. Like every
feature, lost on lapse — a lapsed organization's public courses pitch again
until payment is fixed.
_Avoid_: no-ads, white-label (a different, broader promise)

**Seat**:
A learner slot an organization's plan includes or has bought.
_Avoid_: licence, member, user

**Ceiling**:
A hard per-period count with no purchase path around it, unlike a seat or a
source cap that can be bought past. Its refusal carries no upsell, because there
is nothing to sell — a stranger reading a public course cannot buy more sessions.
_Avoid_: cap, limit

### What it costs

**Generation**:
One metered AI call — a chat turn, a source's digest, an image. The unit credits
are spent in.

**Credits**:
The one noun for what an allowance and a top-up both hold, and for what a
generation costs.

**Allowance**:
The credits a plan grants for the current billing period. Resets each period and
does not carry over.
_Avoid_: quota, limit

**Top-up**:
Credits bought once and spent only once the allowance is exhausted. Carries over
until spent.
_Avoid_: extra credits, refill

### How the answer is given

**Decision**:
What a policy answers with: the facts the caller asked for, plus the refusal to
raise if there is one. One answer serves both "would this be allowed" and "why
not", so a surface predicting a refusal and the code raising it cannot disagree.
_Avoid_: check, result, verdict

**Refusal**:
The reason an organization may not do something, worded identically whether it
reaches a client as a thrown error or as an answer a surface rendered ahead of
time.
_Avoid_: error, denial, rejection

**Lapse**:
A subscription whose grace period after a failed payment has run out. A lapsed
organization loses every feature its plan sold it, not only the one it was
reaching for.
_Avoid_: expired, cancelled, overdue
